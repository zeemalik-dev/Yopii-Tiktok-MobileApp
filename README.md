Yoopii is a modern mobile social commerce platform inspired by short-form video experiences. Built with Flutter, it delivers a smooth creator-first ecosystem where users can browse engaging content, follow communities, share media, chat, and discover products in an immersive social environment.

This app brings together the best parts of short video engagement and e-commerce-driven discovery into a single mobile experience.

## Highlights

- Short-form video feed with vertical scrolling experience
- Creator and community discovery
- Profile management and user stats
- Social chat and direct interactions
- Media posting with image/video upload flow
- Notification center and engagement tracking
- Onboarding and authentication screens
- Mobile-first modern design with a premium visual style

## App Showcase

### Core Experience

- TikTok-inspired feed with infinite-style browsing
- Product-focused content and creator storytelling
- Rich profile pages with follower, following, and sales metrics
- Smooth onboarding flow for account access and sign-in/sign-up

### Screens included

- Splash and onboarding screens
- Sign in / sign up / forgot password flows
- For You feed
- Chat list and conversation screens
- Notification center
- Profile and edit profile screens
- Post creation and media upload flow

## Getting Started

### Prerequisites

- Flutter SDK 3.6+
- Android Studio / VS Code
- Emulator or physical Android device

### Install dependencies

```bash
flutter pub get
```

### Run the app

```bash
flutter run
```

### Build for Android

```bash
flutter build apk
```
